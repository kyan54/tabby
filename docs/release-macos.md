# Tabby {{VERSION}}：SFTP 排序增加取消状态

## 本次改动

- 删除高级排序入口和整个展开编辑面板，不留空白占位；保留原生文件列表的配色、字体、图标、行样式和操作。
- 名称、大小、修改时间表头继续使用单列 **升序 → 降序 → 取消排序**；切换列时只选中该列。
- Shift+点击继续添加、反转、移除指定列，并保留其他列的方向及重新编号后的优先级；Enter/空格同样支持。
- 取消最后一列后持久化空规则；刷新、切换目录、重开面板仍保持取消状态。
- 取消时保留服务器返回顺序；原有目录优先偏好不变，开启时仅稳定分组。
- 旧类型（type）规则因没有可见表头，在读取时过滤；其余规则保留顺序和方向，仅类型排序变为取消。
  打开面板不重写配置，下一次表头操作才保存可见规则，不重置目录优先或其他 SSH 设置。
- 延续 Cyberduck 集成回退，不修改用户已有钥匙串记录或安装中的应用。
